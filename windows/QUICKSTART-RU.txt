Notely для Windows — тестовая версия 0.1

1. Распакуйте весь ZIP в обычную папку и запустите Notely.exe.
   Требуется Windows 11 x64. Права администратора и установка .NET не нужны.
   Сборка пока не подписана; Windows может показать SmartScreen.
2. Введите собственные ключи Deepgram и OpenRouter.
3. Выберите выход звука, который используется в Zoom / Meet / Telemost.
   По умолчанию слушается основной выход Windows. Если звук звонка идёт на
   другую гарнитуру, выберите её явно. Выберите микрофон.
4. Нажмите «Сохранить и начать разговор».

Ctrl+Alt+Space — скрыть/показать (также клик по значку в системном трее).
Ctrl+Alt+I — фокус в поле вопроса.
Ctrl+Alt+S — снимок монитора под курсором и немедленный ответ.
Ctrl+Alt+P — пауза / продолжить.
Ctrl+Alt+стрелки вверх/вниз — прокрутка истории ответов.
Ctrl+Alt+стрелки влево/вправо — ширина окна.
Ctrl+Alt+плюс/минус — размер текста.
Ctrl+V — вставить картинку в поле вопроса; Enter — отправить.
Esc — убрать картинку, затем очистить поле.
Кнопка «Скрин» прикрепляет снимок к будущему вопросу без отправки.

Новый ответ добавляется ниже предыдущих. Прерванная подсказка остаётся
на экране и в контексте. Картинка передаётся модели только в одном запросе;
дальше используется описание «Экран: …» из ответа.

Меню ⋯ или правый клик по значку в трее:
- новый разговор, пауза, модель, профиль, словарь;
- настройки ключей и звука, перезапуск аудио;
- проверка скрытия на снимке, сохранение диагностики, выход.

Профиль, настройки и логи: %LOCALAPPDATA%\Notely
Ключи: keys.dat, защищённый DPAPI для текущего пользователя Windows.
Ключи нельзя переносить копированием keys.dat на другой ПК — введите заново.
Профиль profile.md и словарь keyterms.txt можно копировать между Mac и Windows.
API-запросы используют ваш баланс. Для разовой проверки держите небольшой
баланс/лимит на ключах. Для работы изображения нужна vision-модель.

СКРЫТИЕ ОКНА
Окно исключается из стандартного захвата Windows через WDA_EXCLUDEFROMCAPTURE.
Это не гарантия для любого клиента/драйвера. До реальной встречи обязательно
проверьте трансляцию со второго устройства. Отдельно проверьте «весь экран»
и «отдельное окно». Кнопка проверки делает локальный снимок, она не доказывает
невидимость в конкретной версии Zoom / Meet / Telemost.
Значок Notely в трее и имя процесса не маскируются.

ПРОВЕРКА НА ЖИВОМ ПК (пока обязательна)
1. Слышит YouTube/звук звонка, индикатор собеседника реагирует.
2. Микрофон реагирует, голос владельца только пополняет контекст.
3. Несколько вопросов подряд, прерывание ответа, прокрутка вверх.
4. Скриншот, Ctrl+V картинки, следующий вопрос по содержимому экрана.
5. Zoom, Meet, Telemost: видно ли окно на втором устройстве?
6. Смена гарнитуры и микрофона, сон/пробуждение, пропажа сети.
7. Новый разговор во время ответа, многомониторность, масштаб 125–200%.

Если что-то не работает: ⋯ → «Сохранить диагностику». Отправьте
diagnostics.json и notely.log. Они не содержат API-ключей, текста разговора,
профиля, скриншотов или ответов. Названия аудиоустройств в диагностике есть.
Локальный снимок invisibility-test.png — личные данные; отправляйте его
только после самостоятельной проверки содержимого.

GitHub Actions проверяет компиляцию, сценарии логики, шифрование ключей,
создание окна, отображение текста и принятие флага скрытия Windows.
Реальный звук, устройства и видеоконференции CI не проверяет.
